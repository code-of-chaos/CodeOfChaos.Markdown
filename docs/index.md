# CodeOfChaos.Markdown Documentation

Welcome to the official documentation for `CodeOfChaos.Markdown`.

## What this project does

`CodeOfChaos.Markdown` provides parsing and editor-related building blocks for working with Markdown in .NET applications.

## Installation

Install the main package from NuGet:

```bash
dotnet add package CodeOfChaos.Markdown
```

You can also reference the source projects directly if you are consuming this repository as part of a larger solution.

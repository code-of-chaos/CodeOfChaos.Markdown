# Getting Started

This guide helps you quickly reference and use `CodeOfChaos.Markdown` in your .NET projects.

## Prerequisites

- .NET SDK installed
- Access to NuGet (or this repository as source)

## Add the package

```bash
dotnet add package CodeOfChaos.Markdown
```

## Reference from code

```csharp
using CodeOfChaos.Markdown;
```

## Basic usage approach

1. Parse or transform Markdown content using the parser components.
2. Use syntax/editor components for richer processing scenarios.
3. Review API docs for namespaces, types, and XML-comment details.
